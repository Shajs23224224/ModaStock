# ModaStock

Sistema web de gestión de inventario especializado en tiendas y marcas de ropa.

El proyecto se desarrollará en diez fases, desde el análisis de requisitos hasta el despliegue y la documentación. La especificación funcional y el alcance inicial se encuentran en `docs/fase-1/`.

## Estado

- Fase actual: 1 — Análisis y especificación.
- Estado: documentación en elaboración.
- Arquitectura y tecnologías: pendientes de validación en la fase 2.

## Objetivo

Administrar productos de moda, variantes por talla y color, existencias y movimientos de inventario con trazabilidad y reglas de negocio consistentes.
